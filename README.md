## ◈ Visão geral

O **Landing Page Hub** é, ao mesmo tempo, um portfólio navegável e um ambiente
para experimentar linguagens visuais distintas. A página inicial não é apenas uma
lista de links: ela oferece filtros por capacidade, previews animados, estudos de
caso, tecnologias e indicadores de complexidade para cada trabalho.

### O Hub oferece

- 🧭 **Navegação contextual** — menu flutuante disponível nas experiências;
- 🎛️ **Filtros técnicos** — 3D, WebGL, Motion, Product UI, Editorial e mais;
- ✦ **Previews vivos** — cada card possui uma representação visual própria;
- 📖 **Estudos de caso** — desafio, design, solução técnica e resultado;
- 📊 **Matriz de complexidade** — leitura comparativa de UI, motion, 3D e backend;
- 📈 **Analytics** — integração global com Vercel Analytics.

## 🗂 Arquitetura

```text
landing-page-hub/
├── public/
│   └── sculpted-silence/              # Acervo fotográfico
├── src/
│   ├── app/
│   │   ├── page.tsx                   # Entrada do Hub
│   │   ├── layout.tsx                 # Fontes globais e Analytics
│   │   ├── (atelier)/                 # Sculpted Silence
│   │   ├── (books)/                   # Cinematic Ink
│   │   ├── (compliance)/              # LegisFlow
│   │   ├── (engineering)/             # Drafted Obsidian
│   │   ├── (fitness)/                 # Densify + Comparison
│   │   ├── (immersive)/               # Spectral Core
│   │   └── (saas)/                    # Nexa + página de contato
│   ├── components/
│   │   ├── hub/                       # Galeria e previews
│   │   └── <projeto>/                 # Componentes isolados
│   └── lib/
│       ├── projects.ts                # Fonte de dados do Hub
│       └── profile.ts                 # Perfil e contato
├── next.config.ts
└── vercel.json
```

Os **route groups** organizam os projetos por domínio sem aparecer na URL. O
catálogo tipado em `src/lib/projects.ts` alimenta filtros, previews, estudos de
caso, capacidades e métricas do Hub.

## ⌘ Executando localmente

### Pré-requisitos

| Ferramenta | Versão recomendada |
|---|---|
| Node.js | `>= 20` |
| npm | `>= 10` |

```bash
git clone <url-do-repositorio>
cd landing-page-hub
npm install
npm run dev
```

Abra **[localhost:3000](http://localhost:3000)**.

| Comando | Ação |
|---|---|
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera o bundle de produção |
| `npm run start` | Executa o bundle gerado |
| `npm run lint` | Executa a análise do ESLint |

---

## ＋ Adicionando um projeto

1. Crie a rota dentro do route group apropriado em `src/app`;
2. isole os componentes em `src/components/<projeto>`;
3. adicione arquivos estáticos em `public/<projeto>`;
4. registre todos os metadados em `src/lib/projects.ts`;
5. inclua o atalho em `src/components/MiniHubMenu.tsx`, se necessário;
6. crie um `README.md` próprio seguindo o padrão desta coleção;
7. valide com `npm run lint` e `npm run build`.

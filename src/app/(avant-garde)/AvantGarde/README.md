## ✦ Conceito

Inspirado nas diretrizes estéticas e físicas de estúdios como *heydamir.design* e *ousmaneballondor.fr*, esta landing page rompe integralmente com templates convencionais de UI kits (sem bordas arredondadas padrão, sem cartões simétricos de 12 colunas e sem sombras suaves).

Uma máquina digital bruta onde física inercial, matemática procedural de shaders e tipografia monumental colidem para criar uma experiência sensorial visceral.

## ✦ Stack Tecnológico

- **Framework**: Next.js 16 (React 19, App Router)
- **3D & Shaders**: Three.js, React Three Fiber (`@react-three/fiber`)
- **Motion & Scroll**: GSAP 3 (`@gsap/react`, `ScrollTrigger`), Lenis smooth scroll
- **Estilização**: Tailwind CSS v4 com paleta perceptual OKLCH
- **Tipografia**: DM Serif Display (Didone editorial) + Space Grotesk (Neo-brutalismo industrial)
